## 🎯 О проекте

Данный скрипт автоматизирует процесс настройки SNI сайта для работы с Reality протоколом. Он выполняет все необходимые шаги: от проверки системы и установки зависимостей до получения SSL сертификатов и настройки Nginx.

### ✨ Возможности

- ✅ **Автоматическая установка** всех необходимых компонентов (Nginx, Certbot, Git)
- ✅ **Проверка DNS записей** и соответствия IP адресов
- ✅ **Автоматическое получение** SSL сертификатов от Let's Encrypt
- ✅ **Случайный веб-шаблон** для маскировки сервера
- ✅ **Визуальный прогресс** с ASCII индикаторами
- ✅ **Подавление технического вывода** для чистого интерфейса
- ✅ **Подробные сообщения об ошибках** с путями решения

---

## 🔧 Требования

- **ОС**: Ubuntu 20.04+ или Debian 10+
- **Права**: Root доступ к серверу
- **Домен**: Зарегистрированное доменное имя
- **Порты**: Свободные порты 80 и 443
- **DNS**: Настроенная A-запись домена

## 🚀 Установка

### Быстрая установка

Подключитесь к серверу по SSH и выполните команду:

```
bash <(curl -Ls https://raw.githubusercontent.com/begugla0/selfsniscripts/main/fakesite.sh)
```


### Ручная установка

Скачать скрипт
```
wget https://raw.githubusercontent.com/begugla0/selfsniscripts/main/fakesite.sh
```

Дать права на выполнение
```
chmod +x fakesite.sh
```

Запустить скрипт
```
./fakesite.sh
```

## 📖 Использование

### 1. Привязка IP адреса сервера к доменному имени

> ⚠️ **Важно**: SNI сайт невозможно поднять без доменного имени!

#### Настройка A-записи

1. Перейдите в панель управления DNS вашего домена
2. Добавьте новую **A-запись**:
   - **Тип записи**: A
   - **Имя**: `@` (или оставьте пустым)
   - **Значение**: IP адрес вашего сервера
   - **TTL**: 3600 (или автоматически)

3. Сохраните изменения
4. **Ожидайте обновления DNS**: от 5 минут до 24 часов

> 💡 **Совет**: Проверить распространение DNS можно на [whatsmydns.net](https://www.whatsmydns.net/)

---

### 2. Запуск скрипта

#### Шаг 1: Подключение к серверу

Подключитесь к серверу через SSH:
```
ssh root@your-server-ip
```

#### Шаг 2: Выполнение команды установки

```
bash <(curl -Ls https://raw.githubusercontent.com/YukiKras/vless-scripts/refs/heads/main/fakesite.sh)
```

#### Шаг 3: Ввод данных

**Введите доменное имя:**
```
Введите доменное имя: example.com
```


**Выберите порт (опционально):**
```
Введите внутренний SNI Self порт (Enter для 9000): [нажмите Enter или введите другой порт]
```


#### Шаг 4: Ожидание установки

Скрипт автоматически:
- Проверит систему
- Обновит пакеты
- Установит необходимые компоненты
- Проверит DNS записи
- Получит SSL сертификат
- Настроит Nginx


#### Успешная установка ❤️

Логи сохраняются в `/tmp/sni_setup_*.log`

## 🔧 Решение проблем

### ❌ Ошибка: "Порт 443/80 занят"

#### Причина
Порты 80 или 443 уже используются другим процессом (обычно VLESS на 443 порту).

#### Решение для 3x-ui панели

1. Откройте 3x-ui панель → **"Инбаунды"**
2. Найдите подключение на порту 443
3. **Временно отключите** его (переключатель справа)
4. Запустите [скрипт установки](#2-запуск-скрипта) заново
5. ⚠️ **После настройки обязательно включите обратно!**

#### Решение для Marzban панели

1. Откройте Marzban → **"Настройки"**
2. Найдите настройку порта VLESS
3. **Временно измените порт** на другой (например, 8443)
4. Нажмите **"Сохранить"** и **"Перезагрузка ядра"**
5. Запустите [скрипт установки](#2-запуск-скрипта) заново
6. ⚠️ **После настройки верните порт обратно на 443!**

#### Альтернативное решение (вручную)

Найти процесс, занимающий порт:
Проверить порт 443
```
sudo lsof -i :443
```

Или с помощью ss
```
ss -tulpn | grep :443
```


Остановить процесс (замените PID на реальный):
```
sudo kill -9 PID
```

### ❌ Ошибка: "A-запись домена не соответствует внешнему IP сервера"

#### Причина
DNS записи еще не обновились или домен содержит опечатку.

#### Решение

1. **Проверьте правильность домена** при вводе
2. **Подождите обновления DNS**:
   - Обычно: до 24 часов
   - В редких случаях: до 72 часов

3. **Проверьте распространение DNS**:
На сервере
```
dig +short A ваш-домен.com
```


Или онлайн: [whatsmydns.net](https://www.whatsmydns.net/)

4. **Проверьте A-запись** в панели DNS:
- Убедитесь, что указан правильный IP
- Проверьте, что используется `@` или пусто в поле "Имя"
- TTL должен быть разумным (3600 или меньше)

---

### ❌ Ошибка: "Не удалось получить SSL сертификат"

#### Возможные причины и решения

**1. Порты 80/443 заблокированы файрволом:**
Откройте порты
```
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw reload
```


**2. Домен не резолвится:**
Проверьте DNS
```
nslookup ваш-домен.com
```


**3. Лимит Let's Encrypt достигнут:**
- Let's Encrypt имеет лимит: 5 сертификатов на домен в неделю
- Подождите неделю или используйте поддомен

**4. Nginx не остановлен:**
Убедитесь что Nginx остановлен
```
sudo systemctl stop nginx
```

Запустите скрипт снова

---

### ❌ Ошибка: "Не удалось определить внешний IP сервера"

#### Причина
Проблема с интернет-соединением или сервис ipify.org недоступен.

#### Решение

Проверьте интернет-соединение
```
ping -c 4 google.com
```

Проверьте внешний IP вручную
```
curl https://api.ipify.org
```
```
curl ifconfig.me
```


Если команды не работают, проверьте настройки сети сервера.

---

### ❌ Ошибка: "Система не поддерживается"

#### Причина
Скрипт поддерживает только Ubuntu и Debian.

#### Решение

- Ubuntu 20.04+
- Debian 10+

Проверить систему:
```
cat /etc/os-release
```
